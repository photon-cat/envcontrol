┌─────────────────────────────────────────────────────────────────────────────┐
│ 8. KEY DISCOVERIES                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

    ✓ Protocol is BIDIRECTIONAL (command → status)
    ✓ Frames are INTERLEAVED in data stream
    ✓ THREE command types cycle every 900ms
    ✓ Variant byte (0x35/0x65) controls relay activation
    ✓ Trailer byte is FIXED per command type, NOT a checksum
    ✓ Relay activation is INSTANT (within 100ms frame)
    ✓ Status response confirms relay state

    ✗ Checksum: NOT FOUND (XOR, SUM8, 2's complement tested)
    ✗ 5-board cycling: NOT OBSERVED (only 3 command types exist)
    ✗ Intermediate relay states: NOT CAPTURED (binary ON/OFF)
